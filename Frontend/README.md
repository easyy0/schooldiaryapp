# Frontend Setup

1. Go to the frontend directory:

```bash
cd Frontend
```

2. Create your local environment file from the example:

```bash
cp .env.example .env
```

On Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

3. Install dependencies:

```bash
npm install
```

4. Run the frontend:

```bash
npm run dev
```

The frontend runs by default at:

```text
http://localhost:5173
```
